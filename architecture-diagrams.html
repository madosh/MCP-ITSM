Key Architecture Features

  • 3-Tier Architecture: Frontend (React), Backend (Express), Database (MongoDB)
  • MCP Integration: Model Context Protocol server for LLM interactions
  • Security Layers: JWT authentication, role-based authorization, input validation
  • Multi-ITSM Support: ServiceNow, Jira, Zendesk connectors
  • Error Handling: Global error boundary, structured logging

Authentication & Authorization Flow

Complete user authentication and protected resource access flow

sequenceDiagram participant User participant Frontend participant PrivateRoute participant AuthService participant API participant AuthMW participant UserModel participant MongoDB User->>Frontend: Navigate to /dashboard Frontend->>PrivateRoute: Check authentication PrivateRoute->>AuthService: isAuthenticated() AuthService->>AuthService: Check localStorage token alt No token AuthService-->>PrivateRoute: false PrivateRoute->>Frontend: Redirect to /login Frontend->>User: Show login page User->>Frontend: Enter credentials Frontend->>API: POST /api/auth/login API->>AuthMW: validate(loginSchema) AuthMW->>UserModel: findOne({ email or username }) UserModel->>MongoDB: Query users collection MongoDB-->>UserModel: User document UserModel->>UserModel: comparePassword() UserModel->>UserModel: JWT.sign() UserModel-->>API: { token, user } API-->>Frontend: 200 OK + token Frontend->>AuthService: Save token to localStorage Frontend->>User: Redirect to /dashboard else Has token AuthService-->>PrivateRoute: true PrivateRoute->>Frontend: Render Dashboard Frontend->>API: GET /api/integration (with token) API->>AuthMW: authenticate() AuthMW->>AuthMW: Verify JWT token AuthMW->>UserModel: findById(decoded.id) UserModel->>MongoDB: Query users MongoDB-->>UserModel: User data UserModel-->>AuthMW: User object AuthMW->>AuthMW: Check isActive AuthMW->>API: req.user = userObject API->>AuthMW: authorize(['admin', 'integrator']) AuthMW->>AuthMW: Check req.user.role alt Authorized AuthMW->>API: next() API-->>Frontend: 200 OK + data Frontend->>User: Display integrations else Unauthorized AuthMW-->>Frontend: 403 Forbidden Frontend->>User: Show error message end end

Authentication Features

  • JWT Tokens: Secure token-based authentication with 1-day expiration
  • Password Hashing: bcryptjs for secure password storage
  • Role-Based Access: Admin, User, Integrator roles with granular permissions
  • Active Status Check: Disabled accounts are rejected even with valid tokens
  • Protected Routes: Frontend guards prevent unauthorized access

Access Control Features
